## Goal
Deliver feature by spec with testable acceptance criteria.

## Procedure
1. Confirm the working context.
2. If the context is `projects/<nome>`, read the project process and repo scope.
3. If the context is `.workbench`, use the repository flow without TASK.
4. Write/confirm feature spec (`templates/feature-template.md`) when applicable.
5. Define acceptance criteria and edge cases.
6. Implement incrementally with small commits.
7. Add tests for new behavior.
8. Update docs/specs and ADR if architectural decision exists.
9. Open PR with evidence and risk score.

## Done criteria
- Acceptance criteria validated.
- Tests passing.
- Checklist complete.
- PR opened (not approved).

# {{project_name}} — Knowledge Base

> Estrutura de conhecimento do projeto {{project_name}}.

## Estrutura

```
knowledge/
├── backlog/
│   ├── features/     ← Feature specs de negócio
│   └── bugs/         ← Bug specs
├── specs/            ← Specs técnicas executáveis
└── decisions/        ← ADRs e decisões arquiteturais
```

## Como usar

- `/refinar` — Refinar ideia em feature/bug spec
- `/pipeline` — Pipeline completo de spec → implementação
- `/execute-spec` — Executar spec modular
